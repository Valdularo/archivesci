Submit Your Logs

If you have any logs, be it personal or from a live event, that you wish to share with us, all you need to do is submit them through this simple form below. After each log has been submitted Othinn will personally review it, and if it's deemed suitable will be added to Archival Science.

I'm afraid that we can only accept logs in .txt format. The best way to submit logs to is first run them through Procurator's Chatlog Formatter, using the HTML option. Then copy the result into a notepad file and save it to an area of your computer you can readily access.

If possible, can you please name your log something like [AuthorName][Date][4-16 Character Description].txt. If you attempt to upload a log with the same name as one which already exists on the server, you'll get an error message asking you to rename it and try again. You can use an underscore character _ to seperate words in your title if you wish, these will later be interpreted as spaces.
