Basic Data Tap/Data Tap/Advanced Data Tap

Use this tool with your Siphon Data Node ability to pull $Information from a node.




Data Siphon 1.0

Data Siphons use a more efficient tapping algorithm than Data Taps, resulting in increased tap speed and improved data integrity.




Data Siphon 2.0

An improvement over the original Data Siphon, the 2.0 version has improvements in both tap speed and data integrity. This comes at a price, however, as the data integrity improvements not only pull code fragments out of nodes more frequently, but sometimes active (and hostile) programs as well.




Data Siphon 3.0

The most advanced Data Siphon available, this is the fastest and most dangerous of the Data Siphon series.




Data Extractor 1.0

The Data Extractor line takes a more aggressive approach to retrieving data from nodes. As a result, it is more dangerous to use, and may attract agents in restricted areas. This intial model is not as fast as some of the data siphons, but can pull more info out of a node and is more likely to pull out complete fragments.




Data Extractor 2.0

This improved Data Extractor can match the speeds of the best of the Data Siphons and can pull even more extra info out of a node than its predecessor. Unfortunately, some data integrity was sacrificed to gain speed, and more powerful hostile programs are sometimes attracted to its use.




Data Extractor 3.0

This advanced Data Extractor solves the data integrity problem in its predecessor and boasts high speeds, good data integrity, and a large amount of extra info. Very powerful programs may be retrieved by this tool, so any Data Miner using it should be sure to load strong combat abilities.




Data Scrambler 0.4

This new type of data tap is incomplete and highly experimental. Although its base speed is relatively low, it pulls in a great deal of extra info thanks to its highly disruptive nature, putting its effective tap rate very close to the best of the Extractor line. Its disruptive effects cause code fragments to appear less frequently, but when they do appear, several appear at once. The disruptive effects result in a very high chance of hostile attention, and may even attract agents in neighborhoods where you are normally safe.




Datamine Tap

This data tap has tapping properties similar to a Data Scrambler 0.4, but returns three times as much $info. It cannot be taken out of the Datamine construct. It will revert the holder to their normal state if they try using Master Shadow.
