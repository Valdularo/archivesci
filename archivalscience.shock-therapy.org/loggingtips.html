Logging Tips

Tip 1: LogChatOnStartup = 1

Do you ever forget to log an event, or start logging halfway through? I used to do that, until Rarebit pointed out a very helpful useropts command. Add this to your useropts.cfg file ...

LogChatOnStartup = 1

If you don't have a useropts file, just start up a text file program such as Notepad, add the above command, click "Save As", and name the file "useropts.cfg". Remember to put it in your "The Matrix Online" folder found within the "Monolith Productions" folder.

As the name suggests, this command starts your chat log automatically every time you log on. And it will stay on until you type /logstop, or until you log off. This is very helpful if things happen without warning, like Ookami suddenly appearing at Tabor West. And if you're someone with an unstable Internet connection (such as myself), you won't have to scramble to type /logstart or hit a macro every time you reenter the game.

Your chat log is located within your "The Matrix Online" folder. Click on the folder named "Profiles", then click on the folder that has the same name as your login name. There should be a file called "chat.txt" there. This is your chat log.

Whenever you have the time, go through the log you've made, then copy and paste all the LE and LESIG character dialogue you've caught into separate text files. Personally, I like to make sure I've found all the dialogue by inputing the names of every LESIG character on my server into the "Find" tool, just in case I forgot who was on, or I caught some dialogue and didn't notice. Make sure that "Word Wrap" in the text file you're copying the dialogue to is unchecked, or else the log will become one big clump of text after you've saved it, instead of nice and orderly.

I'm guessing you don't want your chat log's file size to reach into the gigabyte range, so it's best to reduce it when you're done with it. After you've made sure you've copied and pasted all the LE and LESIG dialogue, you can either select all the text and delete it, or simply delete the "chat.txt" file (a new one will be created when you start logging again).

Tip 2: Saving Details using screenshots

Right click on a character, and you'll see "Details" among the various options that appear. The best way to save this information is via screenshots. Hit F12 to make a screenshot. The screenshots you make are located in your "The Matrix Online" folder.

Various items in the game also have a Details section. To access this, go into your inventory, right click on an item, and click "Details".

Note that you can access a character's Details even if you are in Interlock with them. Simply click on the character and it should come up.

Tip 2: Saving emails

One way to save emails is to set the game to Window mode, then take a screenshot of your desktop by hitting Print Screen, then pasting the results in picture application like Paint or Photoshop.

Another way is to use the free program "VMN Toolbox".
