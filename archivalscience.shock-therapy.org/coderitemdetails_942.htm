Communications intercept. Transmission detected Wed 16th of Apr 2008 at 07:29 AM by Othinn. Communique follows:





Item Decompiler

This tool allows you to use your Decompile Item ability to take an item down to its code bits. If you are successful, you will learn its Code Structure. If you already know the Code Structure, you will recover some code bits from the item.




Crypto Tool

This tool lets you use your Cryptography ability to encrypt and decrypt code objects in your inventory.




Code Compilier Tool

This tool allows you to use your Compile Items ability to compile a copy of any item for which you have the item code in your code archive.




Repair Items Tool

Use this tool in conjunction with your Repair Items or Minor Repairs ability to restore stability to a broken item. Repairing an item removes a point of its purity. If an item has no purity left, it cannot be repaired.




Code Analyzer Tool

Use this tool with the appropriate code writing abilities to access your library of code structures. This will allow you to attempt to write item or ability codes, provided you have the appropriate code fragments.
